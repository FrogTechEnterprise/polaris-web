# Polaris Marketing Web (sin Skywork)

Proyecto estático, responsive y sin dependencias externas de generación.

## Estructura

- `index.html`: estructura semántica de la landing.
- `assets/css/styles.css`: estilos, sistema de diseño y animaciones fluidas.
- `assets/js/main.js`: navegación móvil, animaciones de entrada y utilidades UI.
- `assets/images/`: imagenes del proyecto (hero y about conectadas, foto de perfil integrada).
- `assets/icons/`: iconos propios en SVG/PNG.

## Orden de bloques (según requisitos)

1. Hero principal.
2. Bloque "Por qué lo hacemos".
3. Bloque "Qué hacemos".
4. Bloque "Quiénes somos".
5. Bloque sectores/clientes (sin logos protagonistas).
6. Contacto.
7. Footer legal.
